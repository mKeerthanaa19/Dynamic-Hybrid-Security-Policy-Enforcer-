# Dynamic-Hybrid-Security-Policy-Enforcer-

A full-stack security system combining rule-based defenses with 
an ML-powered anomaly detection engine.

## What it does
- Scores each login attempt on a 0–100 risk scale using Isolation Forest
- Detects brute force, credential stuffing, and bot activity in real time
- Sends automated Gmail alerts on high-risk anomalies
- Admin dashboard to visualize live risk scores and blocked IPs

## Tech Stack
- Python, Flask, Scikit-learn (Isolation Forest)
- Node.js / Express
- REST APIs, JSON
